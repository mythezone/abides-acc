标准格式软件著作权申请材料的 LaTeX 文档类

文档类的作用

引入这个 mancls 文档类后，直接在 latex 编写说明书，并引入源码路径，就可以得到两份标准格式的说明书和源码文档。

文档类已上传到 GitHub：fncokg/SoftwareCopyright: 标准格式软件著作权申请材料的 LaTeX 文档类 (github.com)

使用方法

调用文档类：
若文档为软件说明书，直接调用：\documentclass{mancls}。
若文档为源码文件，加 code 选项：\documentclass[code]{mancls}
在导言部分将\title 定义为你的软件名，如\title{素数生成软件 V1.0}
开始编写文档：
若文档为软件说明书，直接编写内容，无需手动添加标题与目录。
若文档为源码文件，直接使用\lstinputlisting 引入文件源码文件，并将样式修改为 codestyle 即可，如：\lstinputlisting[style=codestyle]{main.py}
API 参考和实现细节

Options

code：标明本文档是源码文档，否则是说明书文档
noheaders：不使用页眉
Commands

\code：提供一个 Markdown 效果的代码框
\bs：\textbackslash 的 alias
\maketitle：重写了\maketitle，提供一个垂直居中\@title+“使用说明书”字样的标题页。文档会自动加载标题页。
\contens：一个独占一页、没有页眉的目录页。文档会自动为说明书文档在标题页后加载目录页。
lststyle

codestyle：自动隐藏注释、隐藏空白行、允许换行的 listings 样式，默认语言为 Python。若将语言改为其他语言，只需要将 codestyle 定义中的 language 键值和两个 morecomment 键值改掉即可，例如 C++改为 language=C++,morecomment=[is]{/_}{_/},morecomment=[il][//]。
codestyleln：同上，但在左侧加注行号
Headers

页眉样式居中显示\@title，右侧显示第 X 页

PageSize

源码文档中，调整页面大小至每页 50 行以上源码。 注：直接\geometry{textheight=50\baselineskip}着实有点丑，所以我配合了\renewcommand{\baselinestretch}{}。

# [一、\*\*\*]()简介

    发热头罩是一款戴于头部的发热产品，头罩内安置有发热丝,通过发热头罩系统***控制可控硅通断的时间来设置温度。发热头罩有3个加热档位可选择，分别为：40℃、50℃、60℃，以及3个工作时间档可设置，分别为：15分钟、30分钟、60分钟，达到选择的工作时间后发热头罩会停止工作并关机。

# [二、\*\*\*]()开发以及运行环境

该**\*\***-IDE3000 为代码编辑和编译工具，通过 C 语言编写，以 E-link 和 e-WritePro 为**\*调试工具开发的，运行环\*\*\*\***片机。

# [三、总体设计]()

    ***的实际使用框图如下图所示，它以管理层的形式连接过零信号检测系统、2个KEY按键、发热系统和显示部分。

其中，过零检测系统用于对交流电的频率和波形的上半周和下半周是否有回到零点进行检测，利用好交流电过零点的一瞬间实现对可控硅的关闭，也就是控制发热头罩的发热丝开关是否关闭。如果没有过零检测，那么可控硅一旦导通就无法关闭；

KEY 按键作为人机交互途径之一，用于控制发热头罩的开关机、温度设置、时间设置。KEY_1(时间档位)，用于用户设置发热头罩运行的时间，可设置：15 分钟、30 分钟、60 分钟 3 个时间段。开机默认时间为 15 分钟，且设定好时间后相应档位灯会每一秒闪烁一次，当发热头罩运行的时间达到设定的运行时间时，它将会停止工作并关机。KEY_2(加热档位)，用于用户选择加热的温度，可设置：40℃、50℃、60℃ 三个温度。

另外，显示部分为 6 个 LED 显示，分别为 2 个红色 LED、2 个橙色 LED、2 个绿色 LED。

过零检测，过零检测指的是在交流系统中，当波形从正半周向负半周转换时，经过零位时，系统作出的检测。可作开关电路或者频率检测。系统检测到零位时，要让可控硅在零位或者零位附近时触点导通或者断开。

按键检测部分通常用于人机交互途径，本机两个独立按键，主要功能：1、用于发热头罩系统的启停和切换温度模式。2、选择不同的时长工作。

显示部分，本机使用的是 LED 指示灯，用于显示发热头罩系统的必要信息。显示部分和 KEY 按键部分一起作为人机交互途径，使得发热头罩系统的运行可控。

发热头罩系统\*\*\*总体框图如图 3-2 所示，它由五个模块构成：过零检测模块、按键模块、显示模块、发热系统模块、功能实现模块。发热头罩系统首先进入的是按键检测模块，通过确认按键是否短按开机，然后，系统检测过零模块是否正常，过零正常即可正常控制发热系统模块，再执行功能实现模块与显示模块。

![]()

图 3-2 发热头罩系统\*\*\*总体框图

按键检测模块，关机状态下短按档位按键，此时开机，开机状态下长按档位按键（约 2 秒），此时关机。开机默认在加热低档模式工作，开机状态下短按 1 次按键切换至下一个模式，再短按再切换至下一个模式，在加热低档模式、加热中档模式、加热高档模式循环切换,相应档位模式的 LED 灯点亮，其余档位模式 LED 灯熄灭。

功能实现，第一次开机后，自动检测的按键是否短按，如果没有按键短按，\*\*\*进入的加热低档模式，并以该模式设置的全功率加热时间和设置的工作时长运行，相应档位 LED 灯常亮，相应的时间档 LED 灯显示为闪烁状态，如果有按键短按则切换至下一个模式，并以该模式设置的全功率加热时间和设置的工作时长运行，相应档位 LED 灯常亮，相应的时间档 LED 灯显示为闪烁状态。每个档位的全功率加热时间都不一样，当单片机运行够当前设置的全功率工作时间后，发热系统将开始由全功率加热转变为 DutyCycle 加热。运行够设置的时间档工作时长后，发热头罩将停止加热并关机。
