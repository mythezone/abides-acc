# CALIBRAX

## Introduction

1. 对于金融市场来说仿真器的重要性
2. 现有仿真器的不足
   1. 仿真规模不足：宏观经济的仿真器声称已经可以做到 1:1 全球经济规模，但是这些仿真器通常只关注宏观经济指标，缺乏对微观经济行为的深入模拟。也难以模拟复杂的金融市场行为，通常只能在较小范围内（几只股票）进行仿真，难以捕捉到市场的全貌，因而也难以洞察整个板块或市场的走向，对于投资者和政策制定者来说，缺乏足够的参考价值。
   2. 时间尺度不足：现有的仿真器通常只能模拟短期行为，无法捕捉长期趋势和周期性波动。虽然对于日内高频交易等短期交易策略有一定的价值，但是对于长期投资者和政策制定者来说，缺乏足够的参考价值。
   3. 交互性不足：现有仿真器提供的交互功能有限，比如用户难以分析大单对市场的冲击的影响，或者不同交易策略的效果。Agent 通常只能对一支股票进行交易，不能通过配置资产组合来模拟更复杂的投资策略。
   4. 仿真报告不足：现有仿真器通常只能记录交易过程和交易结果，这种报告体现在宏观层面，对于 Agent 个体的分析记录不足，难以判断持有某类策略的 Agent 的行为和策略是否在整个市场中具有优势。也难以进行一些金融学实验，比如测试某种交易策略在不同市场条件下的表现。
   5. 仿真程度不足：现有仿真器虽然已经添加了大量真实市场中的细节，比如消息延迟、交互请求等，但是对一些重要的交易细节的模拟仍然不足，比如交易成本、用户持仓等。
   6. 仿真器难以校准：现有仿真器含有大量控制参数，虽然为模拟器带来了灵活性，但是也使得仿真器难以对真实市场进行校准。部分仿真器虽然可以通过真实数据指导仿真行为，但是没有对这种指导行为做出明确定义，难以判断这种指导是否合理，也难以区分在这种指导下的 Agent 策略的回报率的与通过简单的历史数据回撤方式有什么本质区别。
3. CALIBRAX 的目标和优势

   1. CALIBRAX 旨在提供一个 1:1 的大规模金融市场仿真器，能够仿真整个金融市场的参与者行为。
   2. CALIBRAX 除了能仿真日内的短期交易行为，还能提供日间交易和长期投资的仿真，能够捕捉长期趋势和周期性波动。
   3. CALIBRAX 提供了丰富的交互功能，用户可以分析大单对市场的冲击的影响，或者不同交易策略的效果。
   4. CALIBRAX 提供了详细的仿真报告，能够记录 Agent 个体的行为和策略，方便进行金融学实验。
   5. CALIBRAX 提供了高程度的仿真，能够模拟交易成本、用户持仓等重要的交易细节。
   6. CALIBRAX 提供了明确的校准方式，能够通过真实数据指导仿真行为，并且能够区分在这种指导下的 Agent 策略的回报率的与通过简单的历史数据回撤方式有什么本质区别。

   证券市场仿真系统是对真实市场从微观视角（订单）进行的低成本计算模拟【本质上是一个多智能体计算系统，包括订单撮合维护和各种模拟交易者行为（下订单的逻辑）的 agents 的简要介绍，以及他们之间的交互关系等。目的是让人对证券市场仿真系统的工作原理有个直观、粗浅的认识】

   我们关心两个问题：
   1）任何仿真都是对真实系统的近似，那金融市场仿真可以近似到什么程度？
   2）能否/如何以最低的资源消耗达到这个程度？

   对于第一个问题：现有的金融市场仿真系统，有多准？从结构和数据两方面讲。从结构方面来说，就是跨资产、跨日、大规模智能体，现有的仿真器不能很好支持。从数据方面讲，可以通过配置 agent 来实现更准的数据仿真，现有的仿真器没有这个功能。

   如何实现？四个大点：
   1） 跨资产=》相同 agent 可以向不同资产发送订单=〉不同资产会通过 agent 的行为相互影响。
   2） 跨日=》agent 具备集合竞价和连续竞价两种发送订单行为能力。
   3） 高准度=〉agent 的参数可以进行动态配置，并可根据真实数据进行算法自我校准。
   4） 可扩放性=》订单受资产数、agent 数、agent 行为影响。提升订单处理效率。

   当前瓶颈：
   1）订单处理效率：要做到什么程度才行？现在的仿真器做到了什么程度？
   2）校准效率：一次校准（仿真一次需要多久、迭代多少次），需要多少次校准。按资产和时间独立来算，拢共需要多少核时。实际上，如果考虑跨资产和跨日，agent 参数校准更复杂（为什么）=》显然是难以承受的。

   我们针对这两个瓶颈，如何设计解决的？
   1） 订单簿的数据结构优化：时间复杂度、空间复杂度降低分析
   2） 自校准方法：设计了一种对齐 agent，背景 agent 的处理。只需要一次仿真、迭代一次。理论上节省 xxx 倍核时。

   基于上述设计，我们提出了一个新的仿真系统，叫做 xxxx。在 xxx 数据上验证，该系统具备 xxxx 功能，可以支撑更为广泛的金融分析任务。该系统具备 xxx 性能，经验证可以拓展到 xxx 规模的仿真尺度，具备全尺度的潜力。（实验介绍要重点）
